Request Data Flow

1

User Adjusts Filters in UI

The user changes one of the 4 global filters (Time Period, Warehouse, Category, Order Status) in the Vue sidebar. The composable useFilters updates shared reactive refs, triggering watchers in each view.

2

Vue Component Calls api.js

Each view calls the relevant function in client/src/api.js, passing the current filter state. Active filters are serialised into URL query params (e.g. ?warehouse=WH1&category=Electronics&month=2025-03). The all value is omitted from the request.

3

Axios Sends HTTP GET to FastAPI

Axios sends the request to http://localhost:8001/api/<endpoint>. CORS middleware on the FastAPI side allows all origins in development.

4

FastAPI Filters In-Memory Data

apply_filters() runs sequential list comprehensions over the in-memory Python lists — filtering by warehouse, category, and status. filter_by_month() then handles direct month strings (YYYY-MM) or quarter aliases (Q1-2025 → three month strings).

5

Pydantic Validates Response

FastAPI serialises the filtered dicts through the declared Pydantic response_model (e.g. List[InventoryItem]), enforcing types and stripping unexpected fields before sending JSON.

6

Vue Stores Raw Data in refs, Computes Views

The resolved Axios response is written into a ref (e.g. inventoryItems.value = data). Computed properties then derive what is displayed — totals, filtered lists, chart datasets — without extra API calls. Vue's reactivity system re-renders only affected DOM nodes.

Global Filter System

Time Period
Query param: month Direct: YYYY-MM Quarter: Q1-2025 ... Q4-2025 Default: all
Warehouse
Query param: warehouse Exact string match on order/inventory warehouse field Default: all
Category
Query param: category Case-insensitive match on item category Default: all
Order Status
Query param: status Processing / Backordered / Delivered / Cancelled Case-insensitive. Default: all

Filters are managed in a shared Vue composable (useFilters) and passed as query params through api.js on every data fetch. The inventory endpoint does not support the month filter (inventory has no time dimension).

Frontend Views

Dashboard / (root)

KPI summary cards, revenue charts, low-stock alerts. Supports all 4 filters via /api/dashboard/summary.

Inventory /inventory

Full item list with quantity, reorder point, location, and unit cost. Filters: warehouse, category only.

Orders /orders

Order table with status badges and value totals. Supports all 4 filters.

Demand /demand

Demand forecasts with trend indicators. Also shows backlog items with purchase order status and creation form.

Spending /spending

Spending summary, monthly bar chart, category breakdown, and recent transactions.

Reports /reports

Quarterly performance table and month-over-month trend charts computed from order history.
